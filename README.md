# Amazon-воронка · Telegram-бот · @vadjik

Боевая сборка. Внутри: воронка из 3 видео + 2 кружков, пруфы, лид-магнит за подписку, и Telegram Mini App с тарифами и результатами учеников.

## Что осталось сделать перед запуском

1. **Перевыпустить токен** (был передан в открытую):
   @BotFather → твой бот → API Token → **Revoke current token**.

2. **Задеплоить бота на Railway** — `ДЕПЛОЙ.md`.

3. **Захостить Mini App** на GitHub Pages и задать `WEBAPP_URL` — `MINI_APP.md`.
   (Без этого кнопка «Что входит» покажет тарифы текстом — тоже работает.)

4. **Лид-магнит**: положить `guide.pdf`, задать `CHANNEL_USERNAME`, сделать бота админом канала — `LEAD_MAGNET.md`.

5. **Подправить плейсхолдеры в `bot.py`**: `[X–Y]` (вилка цен) и `[впиши свою формулировку]` (гарантия) в блоке `TXT`.

6. **Пройти бота от /start до конца.**

## Mini App «Что входит в обучение»

Открывается по кнопке на оффере (и по команде `/programs`). Внутри:
- 4 тарифа ($700 / $830 / $1500 / $5800) с детальным разбором что входит;
- 19 результатов учеников с реальными цифрами и скринами;
- бонусы на $1750.

Главный CTA в приложении и в боте остаётся «Записаться на разбор» — цену финально подбираешь на созвоне. Mini App работает как витрина-прогрев, не заменяя разбор.

Хостинг — `MINI_APP.md`. Без `WEBAPP_URL` бот показывает тарифы текстом.

## ⚠️ Нюансы сборки

- **Видео отправлены как файл** → идут как карточка-файл, не inline. Чтобы inline — перешли через «прикрепить → Видео», обнови file_id, убери `"kind": "document"`.
- **Кружки**: 58 сек → `circle_intro`, 47 сек → `circle_fork`. Проверь, не перепутаны ли.
- **Скрины блоков A/B** — через URL postimg.cc. Mini App картинки — локальные (в репо).

| Команда | Кому |
