# НАСТРОЙКА — локальный запуск и команды

Эта инструкция нужна, если ты хочешь запустить бота **на своём компьютере** — для теста, обновления file_id, или просто потыкать перед деплоем.

Для боевого деплоя — см. `ДЕПЛОЙ.md`.

---

## Локальный запуск

1. Установи зависимости (один раз):
   ```
   pip install -r requirements.txt
   ```
   (если `pip` не найден — попробуй `pip3`)

2. Задай токен в переменной окружения и запусти:

   **macOS / Linux:**
   ```
   BOT_TOKEN=твой_токен python bot.py
   ```

   **Windows (PowerShell):**
   ```
   $env:BOT_TOKEN="твой_токен"; python bot.py
   ```

   **Windows (CMD):**
   ```
   set BOT_TOKEN=твой_токен && python bot.py
   ```

3. Должно появиться:
   ```
   INFO Бот запущен. ADMIN_ID=630926654, DATA=...users.json
   ```

4. Открой бота в Телеграме, напиши `/start` — пойдёт воронка.

5. Чтобы остановить — `Ctrl + C` в терминале.

> ⚠️ Если бот уже запущен на Railway, локально его запускать одновременно нельзя — Telegram выдаст `Conflict: terminated by other getUpdates`. Сначала тормози Railway-деплой (Settings → Suspend Service), потом тестируй локально.

## Команды только для тебя (как ADMIN_ID)

### `/id` — получить file_id любого файла

Когда нужно: заменить какое-то медиа в `bot.py`. Например, перезалить кружок или видео в другом формате.

1. Боту → `/id` → он включит режим
2. Перешли боту видео / кружок / фото
3. Бот ответит сообщением со строкой `file_id: ...`
4. Скопируй её в `bot.py` в нужное место
5. Перезапусти бота (локально — Ctrl+C и снова; на Railway — закоммить в git, само пересоберётся)

Подсказки от бота:
- Кружок (video_note) → пойдёт в `circle_intro` или `circle_fork`
- Видео с пометкой `kind: video` → пойдёт в `video_1/2/3`, удали `"kind": "document"`
- Документ → бот скажет, что лучше переотправить как видео

### `/stats` — статистика воронки

Покажет, сколько людей сейчас на каком шаге. Это твой главный замер: где люди застревают — там и докручивай тексты.

Эталонные проценты конверсий между шагами — в `СЦЕНАРИЙ_БОТА.pdf`, раздел 7.

### `/reset` — сбросить себя и пройти заново

Когда нужно: при тестировании. После `/start` бот запоминает твой шаг — без `/reset` ты на повторный `/start` останешься на том же шаге.

## Структура данных

Если запустил бота локально — рядом с `bot.py` появится файл `users.json`. Это база пользователей. Удаление этого файла = сброс всей статистики.

Не коммитить в git! Он уже добавлен в `.gitignore`.

На Railway этот файл должен лежать в Volume (см. `ДЕПЛОЙ.md`, шаг 5).

---

## Если ломается

| Ошибка | Что делать |
|---|---|
| `ОШИБКА: переменная окружения BOT_TOKEN не задана` | Не задал переменную при запуске. См. примеры команд выше. |
| `Unauthorized` | Неверный токен (опечатка / старый, не текущий). |
| `Conflict: terminated by other getUpdates` | Бот уже запущен где-то ещё (на Railway или в другом терминале). |
| `ModuleNotFoundError: telegram` | `pip install -r requirements.txt` забыл сделать. |
