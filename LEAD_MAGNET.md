# Лид-магнит — как настроить

В бот встроен сбор подписок на канал в обмен на гайд «топ-3 ошибки».
Это спасает тех, кого иначе потерял бы — он не вредит основной воронке,
потому что показывается ТОЛЬКО в двух местах:

1. **В догоне после оффера** (через 24 часа, если не оставил заявку) —
   кнопка «Забрать топ-3 ошибки (бесплатно)».
2. **В финале для холодных** — кто в квизе ответил «Пока не готов» или
   «просто изучаю». Им вместо приглашения на разбор показывается гайд.

## Как работает для пользователя

1. Видит предложение «Хотите топ-3 ошибки? Бесплатно, 1 шаг» → кнопки
   «Хочу забрать» / «Пропустить».
2. Жмёт «Хочу забрать» → бот: «Подпишись на канал» + кнопка перехода
   в канал + кнопка «Я подписался».
3. Жмёт «Я подписался» → бот проверяет подписку:
   - подписан → присылает guide.pdf + кнопку «Записаться на разбор»;
   - не подписан → «Пока не вижу подписки, подпишись и нажми ещё раз»;
   - бот не смог проверить → даёт твой контакт, чтобы не потерять.

## Что нужно сделать тебе

### 1. Сделать бота админом канала (обязательно)

Без этого бот физически не может проверить, подписан человек или нет.

- Канал → Управление → Администраторы → Добавить → выбери своего бота.
- Прав много не надо, достаточно стандартных админских.
- Канал должен быть **публичным** (иметь @username).

### 2. Задать username канала

В Railway → Variables добавь:

```
CHANNEL_USERNAME = @твой_канал
```

### 3. Положить гайд

Два варианта на выбор:

**Вариант А — файлом (проще):**
Назови свой гайд `guide.pdf` и положи в репозиторий рядом с `bot.py`
(на GitHub: Add file → Upload files). Всё, бот сам его найдёт.

**Вариант Б — через file_id (если не хочешь хранить файл):**
1. Запусти бота, напиши `/id`
2. Пришли боту свой PDF
3. Бот вернёт file_id
4. В Railway → Variables добавь `GUIDE_FILE_ID = тот_file_id`

Если задан GUIDE_FILE_ID — бот шлёт его. Иначе ищет guide.pdf файлом.

## Как проверить, что работает

1. Пройди воронку до оффера, **не** оставляй заявку.
   (или просто временно поставь в коде DRIP_HOURS["after_offer"] = 0.01
   чтобы догон пришёл почти сразу, потом верни обратно)
2. В догоне нажми «Забрать топ-3 ошибки».
3. Пройди подписку → должен прийти гайд.

Либо: пройди квиз и в конце ответь «просто изучаю» — должен прийти
экран лид-магнита.

## Статистика

Команда `/stats` теперь показывает строку «Забрали гайд: N» —
сколько человек прошли подписку и получили гайд.
